How to read these tables

Train
EV seconds pooled across measured games in 2022–23, 2023–24 and 2024–25, divided by measured GP and 60. Last season is 2024–25.
Last 5 / 10 / 20
Context immediately before G1. Earlier appearances only; these columns stay fixed.
G1–G10
Actual EV minutes in each played game. Games with zero shot attempts still count; games not played do not.
Test
Total EV seconds ÷ measured appearances ÷ 60. G1–G10 above; appearances 1–82 in the four-block table. Decimal minutes: 15.50 means 15 minutes 30 seconds.

Data notes

  • Regular-season games only. Players must have positive total boxscore ice time to count as an appearance. EV TOI comes from nhl_player_game_strength_summaries.toi (seconds), not all-strength boxscore TOI.
  • EV uses the stored strength definition, including empty-net contexts classified as EV. No shot-bucket confidence filter applies to ice time.
  • Missing EV records are excluded from the average, never treated as zero. Train cells show measured/recorded appearance counts. A stored zero remains zero.
  • All five players have EV records for every recorded Test appearance: Forsberg 82, McDavid 82, Pastrnak 77, Coleman 69, Matthews 60. These are available local records, not a claim of complete league source coverage.
  • League average = total EV seconds across measured skater appearances ÷ measured appearances ÷ 60, not an average of these five players. Train includes all available training skaters. Pregame league windows use each Test skater’s prior appearances before his own G1.
  • G1–G10 and the four blocks use each player’s appearance number, not shared dates. League cohorts change as fewer players reach later appearances; a rising league block average alone is not evidence that an individual gains ice time.
  • Last 5/10/20 are fixed immediately before each player’s first Test appearance, drawing from prior regular-season games, never future games or playoffs. Missing records within a window are not replaced by older games. Last season is 2024–25.
  • Train and Last season are observed averages, not stored TOI forecasts. Game results and Test are retrospective references, never pregame inputs.
Read-only calculation source (SQL)

Snapshot from local dynastyiq, 07 Oct 2026. Executed in a read-only transaction; no jobs or model rebuilds.

WITH base AS MATERIALIZED (
SELECT b.nhl_player_id,g.nhl_game_id,g.season_id,g.start_time_utc,g.game_date,s.toi
FROM nhl_boxscores b JOIN nhl_games g USING(nhl_game_id)
LEFT JOIN nhl_player_game_strength_summaries s ON s.nhl_game_id=b.nhl_game_id AND s.nhl_player_id=b.nhl_player_id AND s.strength='EV'
WHERE g.game_type=2 AND g.game_state IN ('OFF','FINAL') AND g.season_id IN ('20222023','20232024','20242025','20252026') AND b.position <> 'G' AND b.toi_seconds>0
), test AS (
SELECT *, row_number() OVER(PARTITION BY nhl_player_id ORDER BY start_time_utc,nhl_game_id) n FROM base WHERE season_id='20252026'
), first_game AS (SELECT nhl_player_id,start_time_utc FROM test WHERE n=1),
prior AS (
SELECT b.*,row_number() OVER(PARTITION BY b.nhl_player_id ORDER BY b.start_time_utc DESC,b.nhl_game_id DESC) rn
FROM base b JOIN first_game f USING(nhl_player_id) WHERE b.start_time_utc<f.start_time_utc
), measures AS (
SELECT nhl_player_id,'train' metric,sum(toi) seconds,count(*) games,count(toi) measured FROM base WHERE season_id<>'20252026' GROUP BY nhl_player_id
UNION ALL SELECT nhl_player_id,'last_season',sum(toi),count(*),count(toi) FROM base WHERE season_id='20242025' GROUP BY nhl_player_id
UNION ALL SELECT p.nhl_player_id,'last_'||w.n,sum(p.toi),count(*),count(p.toi) FROM prior p CROSS JOIN (VALUES(5),(10),(20)) w(n) WHERE rn<=w.n GROUP BY p.nhl_player_id,w.n
UNION ALL SELECT nhl_player_id,'g'||n,sum(toi),count(*),count(toi) FROM test WHERE n<=10 GROUP BY nhl_player_id,n
UNION ALL SELECT nhl_player_id,'test10',sum(toi),count(*),count(toi) FROM test WHERE n<=10 GROUP BY nhl_player_id
UNION ALL SELECT nhl_player_id,'block'||least(4,((n-1)/20+1)),sum(toi),count(*),count(toi) FROM test WHERE n<=82 GROUP BY nhl_player_id,least(4,((n-1)/20+1))
UNION ALL SELECT nhl_player_id,'test82',sum(toi),count(*),count(toi) FROM test WHERE n<=82 GROUP BY nhl_player_id
), results AS (
SELECT nhl_player_id::text entity,metric,round(seconds::numeric/nullif(measured,0)/60,4) value,games,measured FROM measures WHERE nhl_player_id IN (8476887,8478402,8477956,8476399,8479318)
UNION ALL SELECT 'league',metric,round(sum(seconds)::numeric/nullif(sum(measured),0)/60,4),sum(games),sum(measured) FROM measures GROUP BY metric
) SELECT json_agg(results ORDER BY entity,metric) FROM results;
